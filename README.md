# Projeto de Algoritmos em Grafos — MST com Prim e Kruskal

Este projeto implementa e compara dois algoritmos clássicos de Árvore Geradora Mínima (MST): **Prim** e **Kruskal**, utilizando dados reais dos **bairros do Recife**.  
O objetivo é analisar desempenho, custo total e uso de memória em um grafo near-planar criado a partir da distância entre centróides dos bairros.
